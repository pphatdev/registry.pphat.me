# CLI Commands

A complete reference for every command exposed by the **@pphatdev/registry** CLI (v1.5.1).

You can run the CLI via global installation (`pphat`) or directly via `npx`. The following invocations are equivalent:

<CopyCode code="npx pphat <command>" />
<CopyCode code="npx pphatdev <command>" />
<CopyCode code="npx @pphatdev/registry <command>" />

---

## Version & Help

Both short and long version flags are fully supported in v1.5.1+:

<CopyCode code="npx pphat -v" />
<CopyCode code="npx pphat --version" />
<CopyCode code="npx pphat --help" />

---

## `init`

Interactively initializes project preferences and generates a `pphatdev.json` file in the project root.

<CopyCode code="npx pphat init" />

Prompts will guide you through selecting resource types (icons, components), formats (SVG, Next.js, Nuxt.js), and storage paths.

---

View and update configuration settings interactively or programmatically.

### Interactive Configuration

<CopyCode code="npx pphat config" />

### Get Configuration

<CopyCode code="npx pphat config get" />

<CopyCode code="npx pphat config set icons.nextjs.use true" />

<CopyCode code="npx pphat list icons" />
<CopyCode code="npx pphat ls components" />

## `add`

Parent command that downloads icons, components, or AI agent skills using a subcommand grammar.

### `add icon <names…>`

<CopyCode code="npx pphat add icon react vue github" />

### `add component <names…>`

<CopyCode code="npx pphat add component button card modal" />

### `add skill <sources…>`

<CopyCode code="npx pphat add skill pphatdev/skills" />
<CopyCode code="npx pphat add skill pphatdev/skills --skill api-documentation" />
<CopyCode code="npx pphat add skill pphatdev/skills -a claude cursor" />

### Legacy shortcut

For backwards compatibility, `add <name>` with no subcommand is treated as `add icon <name>`:

<CopyCode code="npx pphat add react vue" />

### Options for Icons & Components

| Flag | Long flag | Description |
| --- | --- | --- |
| `-f` | `--format <fmt>` | Output format (`svg`, `nextjs`, `nuxtjs`) |
| `-d` | `--dir <path>` | Destination directory |

## `add-skill`

Hyphenated alias for `add skill`. Installs AI agent skills from GitHub repositories or local directory paths with automated agent detection and lockfile generation.

<CopyCode code="npx pphat add-skill pphatdev/skills" />

### Options

| Flag | Long flag | Description |
| --- | --- | --- |
| `-d` | `--dir <dir>` | Custom target directory for skills (default: `.agent/skills`) |
| `-g` | `--global` | Install skills globally to `~/.agent/skills` |
| `-s` | `--skill <names…>` | Install specific skill(s) by name (`*` for all) |
| `-a` | `--agent <agents…>` | Target specific coding agents (`claude`, `cursor`, `agent`, etc.) |
| `-y` | `--yes` | Skip interactive prompts and install with defaults |
| | `--all` | Install all available skills without prompting |
| `-l` | `--list` | List available skills in the repository without installing |

### Examples

<CopyCode code="npx pphat add-skill pphatdev/skills --skill api-documentation" />
<CopyCode code="npx pphat add-skill pphatdev/skills -a claude cursor" />
<CopyCode code="npx pphat add-skill pphatdev/skills --all -y" />

## `stats`

Show CLI usage statistics from `~/.pphat/history.jsonl` or the remote registry.

<CopyCode code="npx pphat stats" />
<CopyCode code="npx pphat stats --top-icons" />
<CopyCode code="npx pphat stats --top-components" />
<CopyCode code="npx pphat stats --remote" />

### Options

| Flag | Long flag | Description |
| --- | --- | --- |
| `-n` | `--days <days>` | Only include runs from the last N days |
| | `--top-icons [n]` | Show top N most-added icons (default: 10) |
| | `--top-components [n]` | Show top N most-added components (default: 10) |
| | `--remote` | Query aggregated stats endpoint instead of local history |
| | `--clear` | Wipe your own local history file (`~/.pphat/history.jsonl`) |
| `-y` | `--yes` | Skip confirmation prompts for destructive actions |
