# Installation & Quick Start

A quick start guide to using the **@pphatdev/registry** CLI.

---

## Usage via npx (Recommended)

You don't need to install anything. Run the CLI directly using `npx`:

<CopyCode code="npx pphat init" />

The CLI supports multiple convenient aliases (prefixes), so you can use any of the following interchangeably:

<CopyCode code="npx pphat <command>" />
<CopyCode code="npx pphatdev <command>" />
<CopyCode code="npx @pphatdev/registry <command>" />

## Global Installation (Optional)

If you plan to use the CLI frequently across many projects, install it globally on your machine:

<CopyCode code="npm install -g @pphatdev/registry" />

Then use the short commands anywhere:

<CopyCode code="pphat init" />
<CopyCode code="pphat -v" />
<CopyCode code="pphat --version" />

---

## Step-by-Step Workflow

### 1. Initialize your project

Run the `init` command to set up your preferences. It interactively prompts you for configuration and writes a `pphatdev.json` file at the root of your project:

<CopyCode code="npx pphat init" />

*Example interactive setup:*

```text
? What is name of config ? › Default configuration
? What do you want to use ? (required must select one) › Icons

? Which directory you want to use ? (required must select one) › Nextjs format (.tsx)
? Where do you store icon of nextjs ? › components/icons

Success! Configuration saved to pphatdev.json.
```

### 2. View & Manage Configuration

View or update your stored configuration anytime using the `config` command:

<CopyCode code="npx pphat config" />

Or fetch / set specific keys:

<CopyCode code="npx pphat config get" />
<CopyCode code="npx pphat config get icons.nextjs.dir" />
<CopyCode code="npx pphat config set icons.nextjs.use true" />

### 3. Discover Items in the Registry

Browse available icons, components, or installed skills:

<CopyCode code="npx pphat list icons" />
<CopyCode code="npx pphat ls components" />
<CopyCode code="npx pphat list skills" />

### 4. Add Icons or Components

Download icons or components directly into your project using subcommand or hyphenated grammar:

#### Subcommand grammar

<CopyCode code="npx pphat add icon react vue github" />
<CopyCode code="npx pphat add component button card modal" />

#### Hyphenated grammar

<CopyCode code="npx pphat add-icon react vue github" />
<CopyCode code="npx pphat add-component button card modal" />

> `npx pphat add react` (no subcommand) is preserved as a legacy shortcut for `add icon react`.

#### Custom target directory or format

Override your default configuration on the fly using `-d` (`--dir`) or `-f` (`--format`):

<CopyCode code="npx pphat add icon react vue -d src/assets/icons" />
<CopyCode code="npx pphat add component button -f nextjs -d src/components/ui" />

### 5. Install AI Agent Skills

New in **v1.5.1** — install modular AI coding assistant skills (`SKILL.md`) from GitHub repositories with automated agent detection and lockfile generation:

<CopyCode code="npx pphat add skill pphatdev/skills" />
<CopyCode code="npx pphat add skill pphatdev/skills --skill api-documentation" />
<CopyCode code="npx pphat add skill pphatdev/skills -a claude cursor" />

### 6. Remove Resources

Cleanly remove previously downloaded icons, components, or skills:

<CopyCode code="npx pphat remove icon react vue" />
<CopyCode code="npx pphat remove component button" />
<CopyCode code="npx pphat remove skill pphatdev/skills" />

Hyphenated aliases also work (`remove-icon`, `remove-component`, `remove-skill`):

<CopyCode code="npx pphat remove-icon react -f svg -d public/icons" />
<CopyCode code="npx pphat remove-skill api-documentation" />
